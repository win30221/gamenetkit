REALTIME FRAMEWORK · INTERPOLATION

插值開關，差在哪裡？

方塊會自動往返。先選「關閉」，再選「固定」或「自適應」，比較同一份快照的呈現。

1 · 選擇呈現方式

固定緩衝後在快照間取樣；移動更連續，但呈現會晚一點。

2 · 比較網路情境

只影響快照呈現，輸入與連線控制維持直接交付。

3 · 觀察或自己操作

正在連線…玩家 —
收到 tick—
呈現 tick—
插值緩衝—
交付抖動—
快照丟失0
實心：選定的呈現方式外框：同一批交付資料的最新位置

藍色是自己，橘色是其他玩家。也可以開第二個並排視窗觀察彼此。

插值讓呈現更連續，不會降低網路延遲。此範例尚未加入本機預測；關閉「自己的方塊也比較插值」，即可只處理其他玩家。

畫面由同一份 C# SDK 插值接線計算。Unity 專案與加入步驟見 examples/interpolation/README.md。

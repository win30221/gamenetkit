# B3-B 晴日石堡介面

`client/Assets/Resources/TowerDuel/DuelMenuBattlefield.jpg` 是為本專案繪製的 1774×887 介面背景。原創插畫以 B3 盾衛和 [雙門城牆](environment-b3-v1/wall/wall-gates.png) 為造型參考，對應現行 `wall-gates-1` 地圖。

生成提示詞保留中央淺色高牆與兩座常開門洞、左側石板、右側連續泥路、近藍遠紅的炮台主堡與弩砲塔。採用圓潤 Q 版動漫造型、低密度深藍描邊、二到三階硬邊色塊與右上方日光。兩側延伸草地、樹叢、山丘與城牆，以便橫向取景。

Unity 以可用高度換算成 1000 個設計單位。對戰頁插畫固定高 324、寬 648 個單位，置中顯示後依容器寬度取景。卡牌、按鈕和底部頁籤由 UI Toolkit 排版。

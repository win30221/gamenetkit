# 雙橋對決：思考與救援時間調整

日期：2026-11-15（台灣時間）。規則版 `eight-cards-2`，協定維持 3。
本頁記錄第一輪本機調整；目前已隨 `eight-cards-3` 的 [合併站](solo/MERGED_DEPLOYMENT.md) 部署到主網址。

## 第一輪調整

- 六種部隊移速統一降至原本的 80%，保留快慢差異、射程與索敵規則。
- 部隊攻擊週期與前搖約延長 40%，以整數 tick 四捨五入；塔的攻擊週期從 27 改為 38 tick，並集中到共用規則的 `towerCooldownTicks`。
- 火球延遲從 24 改為 34 tick（約 1.13 秒），維持傷害、範圍與塔傷倍率；冰霜仍持續四秒，仍同步減慢移動、前搖與攻擊。
- 正常三分鐘固定每三秒回一點，雙倍回能僅在延長賽啟用。牌費、手牌循環、初始能量、能量上限、血量與單次傷害維持原值。
- 滿能量改為靜態「能量已滿」及淡亮標示，取消催促文案和反覆晃動。延長賽滿能量時同時顯示雙倍回能。
- 單人電腦從前塔後方集結進攻，保留河道附近的防守落點，並對兩席鏡像套用。
- 動畫控制器依新的攻擊週期生成播放速度；正常與單人 WebGL 版本標記從共用規則讀取，避免沿用舊規則版號。

## 驗證

- Go 遊戲伺服器測試與 `go vet` 通過。
- 單人外掛測試與 `go vet` 通過，包含真實後端的出兵、扣費、重連、重賽及退出清理。
- 新增實際交戰測試：無其他傷害時，弓箭手挨盾衛攻擊兩秒後仍可施放冰霜救援；三秒時，未救援者已陣亡，施放冰霜者仍存活。
- 此情境從盾衛開始前搖至第三次命中的時間約從 1.87 秒變成 2.63 秒，增加約 41%，不含接近時間。
- 塔射擊測試確認兩次射擊之間超過一秒，並在一秒半內恢復攻擊。
- 回能測試覆蓋正常時間最後一分鐘、進入延長賽的邊界、雙方雙倍回能與十點上限。
- 單人決策測試覆蓋雙席後場進攻與受威脅路線的前場防守。
- Unity `6000.6.8f1` 編譯及客戶端回歸測試通過，涵蓋前搖／投射物、冰霜動畫、共享法術時間軸、重連、取消、落點及重賽。
- 正常 WebGL 正式建置成功（200.72 秒，0 errors）；單人 WebGL 正式建置成功（208.21 秒，0 errors），兩者版本標記皆為 `eight-cards-2`。
- 正常 WebGL 的實際雙人對局通過，涵蓋六種部隊、兩種法術、勝負、頁面重整與頁內斷線恢復、重賽、滑鼠／觸控及七種畫面尺寸；兩端無 runtime error。
- 部署／HUD 驗證在桌面與手機分別通過 18／14 項檢查。新增滿能量列連續八次取樣，跨越舊版 2.8 秒提醒週期，確認像素位置保持不變。
- 已人工檢視正常時間最後 45 秒與延長賽滿能量畫面，確認提示與回能階段一致，手機文字完整顯示。
- 單人 WebGL 真實後端驗證通過七項檢查，涵蓋電腦練習、靶場、觸控出兵、斷線／重整恢復、房間控制與退出清理；兩端無 runtime error。
- Unity 資產檢查 314 個檔案，0 errors、0 warnings。標準建置流程也重新輸出了場景與六個動畫控制器，保留這些生成檔的更新。

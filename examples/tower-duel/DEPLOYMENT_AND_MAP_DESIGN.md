# 雙橋對決：部署操作與長短路構想

## 本輪實作

- 卡牌移動超過 4 個 UI 單位後開始拖曳，原卡槽留空，半透明卡面從原本位置跟著移動，保留按住的位置及完整卡面比例。
- 移動約卡高的 20% 後，用卡牌中心的抬高落點判斷是否已進入戰場，指標不必完全離開整個牌區。不可部署的地形會吸附最近合法格，小隊須全員合法；模型、金色格與放手部署使用同一落點。能量不足時仍顯示紅色模型，拖回牌區則恢復卡面。
- 觸控瞄準點抬高螢幕高度的 6.5%（限制在 48–72 個渲染像素），滑鼠採 3.5%（20–36 像素）。模型預覽與放手採用相同落點，點選卡牌後直接點地則維持點擊位置。
- 選牌時顯示 1×1 世界單位格線：亮綠格可部署，淡紅格不可部署，金色格標示實際落點。部隊吸附格心，小隊編隊維持原有間距；法術保留自由瞄準與真實半徑。
- 摧毀敵方前塔後，開放該塔同側、從敵方河岸到河岸後 4 單位的矩形前線區。兩座前塔都倒下後連成完整前線；河道、橋面及主堡後方仍不可下部隊。失去己方前塔只會使對手獲得該區。
- 擴區參考《皇室戰爭》拆塔後取得對方橋後矩形區的 pocket 概念；4 單位深度是配合本作 20×30 地圖的設定，並非宣稱複製原作格數。[規則參考](https://clashroyale.fandom.com/wiki/Basics_of_Battle?page=2)、[前塔與 pocket](https://clashroyale.fandom.com/wiki/Princess_Towers)。
- 伺服器逐一驗證小隊落點，全部合法才生成並扣費。重賽恢復原始放置區。地圖雜湊已更新，舊客戶端需與伺服器一起重建。
- 塔顯示「目前 / 最大」血量，部隊顯示目前血量數字；數字置於細血條上方。血條依畫面高度縮放，同高度下加寬視窗不會放大血條，保留主堡啟動、衝鋒與減速狀態。
- 十格能量槽各自連續填充，數字顯示到小數一位；扣費立即反映。能量已滿時亮起「已滿・請出牌」，晃動 0.45 秒後靜止，約每 2.8 秒提醒一次；出牌、結束及斷線恢復時停止。

## 下一張地圖構想：潮汐遺跡

核心是兩條路的時間差：短路施壓，長路集結。保留雙橋與清楚的部署格，但用地形、材質、聲景讓兩路有各自的性格。

| | 急流短橋 | 遺跡長道 |
|---|---|---|
| 輪廓 | 平直的淺色石道與窄石橋 | 沿崩塌遺跡繞行的彎道與木石混合橋 |
| 前塔間路程目標 | 約 15.4 單位 | 約 20 單位，長約 30% |
| 戰術 | 快攻、搶節奏、迫使對方即時回應 | 後排集結、疊兵、較長的攔截窗口 |
| 場景辨識 | 青藍急流、白色水花、低矮河石 | 苔蘚石柱、暖金燈火、樹根與斷牆 |
| 出兵擴區 | 拆塔後開放該側河岸前線 | 拆塔後開放該側河岸前線，維持同樣深度 |

兩側玩家的出生點到同一路橋頭距離相等，地形沿河岸鏡像，避免其中一方天生多走一段。長路使用實際不可穿越的岩壁或遺跡界定彎道，讓路長影響到達時間；裝飾與伺服器導航必須共用同一份碰撞資料。

第一版先不加入隨機潮汐、傷害地形或單邊增益，先用相同兵種同時出發，驗證長路比短路晚約 30% 到達，以及兩個席位的行走時間一致。之後再依快攻／集結的實際勝率調整差距。

本輪交付的是地圖設計方向，現有場景與導航仍使用原本雙橋地形。

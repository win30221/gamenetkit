# 雙橋對決與《皇室戰爭》功能差異及後續項目

分析日期：2026-11-12。比較對象為 `examples/tower-duel` 的現有實作，以及《皇室戰爭》一般 1v1 與周邊功能；活動、2v2 與其他模式的規則另外列出。

**P0 的八張牌、四張手牌循環、新兵種、法術、斷線恢復與同房重賽已實作。** 三種新兵、火球／冰霜、卡面與音效已整合；手機與平板採滿版視野，寬畫面只增加裝飾場地。最新驗收見 [P0_VALIDATION.md](P0_VALIDATION.md)。接下來的玩法擴充是自選牌組、可部署建築、空地反制及單人練習；真人平衡與手機實機驗收仍需完成。

以下優先級與工作量是本專案的開發建議；《皇室戰爭》的功能存在，不代表本作必須採用相同數值或完整加入。已採用的同風格角色、動畫、法術與卡面見 [美術盤點](art/EXPANSION_ASSETS.md)，後續擴卡繼續沿用 [PLAN.md](PLAN.md) 的素材驗證流程。

## 後續實作清單

勾選表示該項功能已實作並有技術驗證；真人平衡、實機觸控與聽感不由自動測試代替。P0 為近期可玩版本，P1 擴充對戰深度，P2 擴充多人服務，P3 為長期產品選項。

工作量 M／L／XL 分別表示中型、跨多個系統與大型架構擴充，僅作相對比較。實際排程需依素材、測試與真人試玩結果拆分。

TD-00～06 的美術／程式已落地，測試證據見 [P0_VALIDATION.md](P0_VALIDATION.md)。TD-03 的職能已有規則與對局驗證，仍需真人確認各種強勢配置的可行解法；TD-07／08 的真機與真人完成條件保留未勾選。

### P1：增加組牌與戰術選擇

- [ ] **TD-09｜自選牌組、卡牌詳情與多組保存（M；既有後續擴充）**：從擴充卡池選八張，顯示費用與職能，先支援本機保存。完成條件：牌組合法性由伺服器確認，對局中不可換牌組；平均費用與卡牌說明正確。真正有組牌選擇需卡池超過八張，建議連同 TD-10／11 擴到 10～12 張再驗收。
- [ ] **TD-10｜可部署建築（L；新增）**：先做一種防禦建築，再考慮產兵／資源建築。完成條件：有部署範圍、佔位、血量與壽命；攻城兵可選它為目標，建築消失時能正確重新尋路／索敵。依賴 TD-01、TD-03，索敵規格與 TD-12 一起確認。

## 後續擴充須維持的契約

- 卡牌已按種類／目標／效果參數驗證，首版仍限制固定八張、固定起手；自選牌組與超過八張的卡池需調整規則載入及握手。
- `deploy` 已分成部隊與法術；新增建築與主動能力需各自定義合法性與效果，維持共用去重及扣費契約。
- 接受出牌、扣費、輪替與確認是同一次權威操作；同一 action 重送回覆相同結果。客戶端只預覽，牌序以伺服器為準。
- 每個收件者只收到自己的能量、手牌、下一張；恢復憑證僅在自己的 welcome。旁觀角色須另外定義可見範圍。
- 重賽會建立新 match，重連會恢復原 match；兩者需分別處理身份、過期指令與待確認出牌。
- 2v2 涉及固定兩席、`[2]` 資料、己方／敵方判定與視角等假設，需當作多人規則擴充。
- 保持即時出牌與輪替模型；卡牌資料化可借用一般卡牌遊戲的做法，本作的回能與出牌時機仍由即時模擬處理。

原始比較依據程式、協定與連結資料；本次 P0 實作另執行 Go 測試、Unity 建置、雙 Player 對局與效能驗證。最新測試、畫面、限制及未完成的實機／真人項目統一記錄於 [P0_VALIDATION.md](P0_VALIDATION.md)。

# Unity 數值調整視窗

從 Unity 選單開啟 **Tower Duel → Balance settings · 數值調整**。

## 調整方式

1. 先停止 Play。
2. 在同一張表比較六種兵的費用、血量、傷害、攻擊間隔、每秒傷害、移速、射程與部署時間。
3. 展開兵種進階設定，調整前搖、索敵、每次出兵數量、範圍傷害或衝鋒；法術另有延遲、持續時間、半徑與效果比例。
4. 按「儲存共用規則」，或按「儲存並重啟本機後端」立即讓新啟動的 Go 後端載入設定。
5. 開啟遊戲場景，按 Play 使用 `http://127.0.0.1:18110` 測試。原本的好友房流程相同。

所有可調整的時間欄位使用 **毫秒（ms）**。目前各兵種部署時間為 **1000 ms**。
伺服器以 30 Hz 模擬，每 tick 約 33.33 ms；輸入會對齊最近的 tick，例如 1500 ms 為 45 tick。
每秒傷害顯示單體持續攻擊估算，小隊採全員總和，方便橫向比較。

塔的血量分為前塔與主堡；目前傷害與攻擊間隔由全部塔共用。
數值不合法時顯示原因並停用儲存，例如攻擊前搖不能長於攻擊間隔。
支援 Undo／Redo；未儲存的變更會有標示。

## 後端如何取得數值

Unity 視窗編輯的是同一份共用規則：

`Unity 視窗 → protocol/rules.json → Go 啟動時載入`

儲存也會同步 `client/Assets/Resources/TowerDuel/rules.json`，兩份內容完全相同。
客戶端與後端依 raw SHA-256 規則雜湊握手；版本不同會被拒絕。
儲存攻擊間隔時也會更新既有攻擊動畫的播放速度。

「儲存並重啟本機後端」透過 `scripts/Start-BalanceServer.ps1` 建置獨立執行檔，
啟動在 loopback 18110。視窗會顯示目前後端是否已套用儲存的規則。
工具只管理自己啟動且核對執行檔路徑／啟動時間的程序；若連接埠已被其他程式使用會提示。
關閉 Unity 時會停止這個工具管理的後端；進入／離開 Play 保留該後端。

執行中的戰局採啟動時載入的設定。本機後端重啟後，以新的對局測試。
已建置的 Windows／WebGL 與公開網站，仍需重新建置與部署才會更新。

## 驗證

- `scripts/Test-Client.ps1` 包含數值表控制項、毫秒換算、輸入驗證、DPS 更新、雙檔儲存及外部修改保護。
- 使用獨立測試檔驗證儲存；保留目前正式規則中的數值。
- `TowerDuelBalanceTests.RunManagedBackend()` 驗證真實 Go 建置、啟動、規則雜湊一致、重啟與停止。
- 測試產物位於 `artifacts/tower-duel/balance/`。

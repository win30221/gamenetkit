進階：時間窗、生命與既有移動設定

補償只接受 0.5 秒內的合法時間。每命中 5 次，目標建立新生命並恢復血量。重設是共享操作，所有分頁都會看到新生命。

既有移動呈現

點畫面後可用 WASD／方向鍵移動自己的角色。目標以伺服器規則自動移動；命中幾何與傷害由應用負責。

Go SDK 保存歷史、限制可回溯時間；應用判定射線與扣血。回溯不搬動當下世界。

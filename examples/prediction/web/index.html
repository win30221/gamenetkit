REALTIME FRAMEWORK · PREDICTION + CORRECTION

按下就移動，回包後怎麼修正？

先比較預測關閉與啟用，再讓伺服器推移角色，觀察直接校正和平滑校正。

1 · 本機預測

立即模擬自己的輸入，收到權威後重播尚未確認的部分。

2 · 校正呈現

預測內部狀態立即校正；平滑只保留短暫的顯示偏移。超過兩單位會直接校正。

這個按鈕真的改變自己的權威位置，不會控制其他玩家。

3 · 觀察或自己操作

取消自動往返，點擊場地，用 WASD／方向鍵體驗按下、放開與反向。失焦會停止輸入。
